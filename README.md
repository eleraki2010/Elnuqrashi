# Alnokrashy POS — النقراشي للأدوات الصحية والسيراميك

تطبيق نقطة بيع (POS) وإدارة مخزون لتجار الأدوات الصحية والسيراميك والتجزئة عموماً.
يعمل التطبيق **بالكامل دون إنترنت** (Offline-first) مع قاعدة بيانات SQLite محلية.

## المنصات المدعومة

- Android
- iOS
- Windows (Desktop)

> ملاحظة: الكود يُبنى للويب أيضاً، لكن طبقة البيانات تعتمد `sqflite` التي لا تدعم الويب،
> لذا التشغيل الكامل على الويب يحتاج استبدال طبقة البيانات (انظر `تقرير_حالة_المشروع.md`).

## التقنيات المستخدمة

| البند | التقنية |
|---|---|
| الإطار | Flutter |
| قاعدة البيانات | SQLite (sqflite + sqflite_common_ffi للديسكتوب) |
| إدارة الحالة | Riverpod |
| اللغة الافتراضية | العربية (RTL) |
| العملة | الجنيه المصري (ج.م) |
| الخط | Cairo (مضمن محلياً) |
| التقارير | fl_chart + تصدير PDF (pdf/printing) |

## الميزات المنفّذة

**Phase 1 — MVP**
- **المنتجات:** إضافة/تعديل/حذف/بحث بالاسم والباركود + التصنيفات
- **المخزون:** تتبع الكميات، تنبيهات الحد الأدنى والنفاد، شاشة جرد
- **نقطة البيع:** بيع سريع، حساب الباقي، الفواتير المعلّقة واسترجاعها، طرق الدفع (نقدي/محفظة/آجل)
- **المبيعات:** سجل كامل مع تحديث المخزون تلقائياً
- **لوحة التحكم:** مبيعات اليوم، عدد الفواتير، الربح، تنبيهات المخزون

**Phase 2 — المتقدمة**
- **المرتجعات:** إنشاء فاتورة مرتجع واسترجاع الكميات للمخزون
- **المشتريات:** تسجيل فواتير الشراء من الموردين مع تحديث المخزون
- **العملاء والموردون:** كشف الحساب، تتبع الديون والمستحقات، تسجيل الدفعات
- **التقارير:** يومية/شهرية/نطاق مخصص مع حساب الأرباح وتصدير PDF
- **المصروفات:** خصم المصروفات التشغيلية من صافي الربح
- **سجل التدقيق:** تسجيل عمليات الإلغاء (Soft Delete)

**Phase 3 — الاحترافية**
- **الباركود:** مسح بالكاميرا أو قارئ USB/Bluetooth (شاشة البيع ونموذج المنتج)
- **الطباعة الحرارية:** إيصالات 57مم/80مم مع خط Cairo المضمّن (عربي offline)
- **النسخ الاحتياطي:** حفظ واستعادة كامل للبيانات (JSON موقّع)
- **المستخدمون والصلاحيات:** تسجيل دخول، دورَي مالك/كاشير، وفلترة الشاشات حسب الدور

**Phase 4 — التوسّعية**
- **Excel:** استيراد/تصدير المنتجات (مطابقة بالباركود والفئة)
- **الواتساب:** تذكير العملاء بالديون عبر روابط `wa.me`
